# Design System

Goals: clean, modern, high-information, little visual noise.

Foundation: shadcn/ui customized locally; React Flow for DAG; Monaco only when useful; keyboard-first.

Color: graphite neutral surfaces, cyan-blue primary accent, semantic green/amber/red. Color is never the only state indicator.

Density: comfortable default, optional compact mode for Build/Review.

Motion: short functional transitions; respect reduced motion.
