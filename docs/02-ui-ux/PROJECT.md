# Knowledge UX

Knowledge é a referência canônica do projeto, não uma etapa que um Goal precisa
concluir.

Seções: Overview/State, ATLAS, Documentation, ADRs, RFCs, Goals, Agents, Skills,
Recipes, Model Policy, Integrations e Run History.

Em projetos externos, Knowledge também oferece um explorer somente leitura para
arquivos textuais. O explorer ignora `.git`, `.atlas-flow`, dependências e
artefatos de build, bloqueia traversal e limita conteúdo. A adaptação ao Project
Atlas aparece como preview revisável, nunca como escrita automática.

Recover Context mostra a ordem canônica de leitura para uma nova sessão.
