# Token Economy

Regras operacionais da primeira fatia:

1. começar pelo router (`AGENTS.md` e `docs/ATLAS.md`);
2. preferir task maps e context packs;
3. carregar summaries antes de fontes completas;
4. usar diff e referências diretas antes de buscar o repositório inteiro;
5. registrar `estimated_tokens` e o método heurístico quando não houver tokenizer;
6. declarar exclusões, mas ignorá-las quando o impacto demonstrar dependência real.
