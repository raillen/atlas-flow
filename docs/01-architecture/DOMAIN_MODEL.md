# Domain Model

## Canonical concepts
Project, Decision, Constraint, Goal, GoalAmendment, AgentRole, Skill, Recipe.

## Operational concepts
Discussion, ProjectDraft, Run, Task, ModelRoute, Runner, Attempt, Evidence, Review.

## Canonical vs operational
Git: manifest, docs, accepted decisions/ADRs, Goals, policies.
SQLite/event log: runs, tasks, attempts, session refs, route decisions, usage and artifact pointers.
