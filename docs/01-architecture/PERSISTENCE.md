# Persistence

## Git — canonical
Project Atlas docs, Goals, ADR/RFC, model policy, manifests, selected Skills/Agents/Recipes, accepted Decisions.

## SQLite — operational
Discussions/session metadata, runs/tasks/attempts, scheduler state, route decisions, runner session ids, usage, transcript/artifact pointers.

Large logs/screenshots/test reports live in artifact storage with stable references.

SQLite schema uses numbered migrations.
