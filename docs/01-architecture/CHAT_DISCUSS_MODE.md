# Chat / Discuss Mode

Discuss is a structured project-definition environment, not a generic chat.

Each turn may yield Message, Decision candidate, Open Question, Constraint, Idea, Assumption and documentation impact.

## Project Draft
Tracks Product, Architecture, UX, Data, Security, Quality, Operations, AI/orchestration and Roadmap with `unknown | partial | sufficient | locked` completeness.

## Finalization
Messages + Decision Ledger + Constraints + Draft → Gap Analysis → Readiness → user resolves/accepts assumptions → Project Atlas artifacts → validation → Phase Goals.

Never implement finalization as a single unstructured "summarize chat" call.
