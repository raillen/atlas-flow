# Development Model Policy

## DeepSeek V4 Pro
Architecture, Goal planning, hard debugging, protocol/security reasoning and final technical review.

## MiMo V2.5 Pro
Implementation, long-context repository work, refactors, integration and alternate review.

## GPT-5.6 Luna
Preferred when available for exploration, unit tests, docs, boilerplate/bulk transformations and low-risk fixes.

Command Code live registry is authoritative for launch availability; probe `cmd --list-models`. If Luna is absent, fallback to MiMo/DeepSeek.
