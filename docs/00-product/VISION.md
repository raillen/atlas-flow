# Vision

Atlas Flow is the reference execution layer for Project Atlas Framework.

## Problem
AI-assisted development is fragmented across chat tools, coding harnesses, model providers and orchestrators. Project decisions frequently remain trapped in conversation history; execution tools often own ephemeral state; and "done" is too often an agent claim rather than a verified outcome.

## Vision
A developer can start with a conversation, progressively formalize decisions, generate durable Project Atlas documentation, turn that knowledge into locked Goals, and execute those Goals through multiple replaceable coding agents and models—without losing project truth when a chat, provider or orchestrator changes.

## Product promise
**From idea to verified implementation, with durable project memory.**

## Principles
1. Git is durable memory.
2. Goal-first, not prompt-first.
3. Protocols before vendor-specific integrations.
4. Explicit decisions before inferred assumptions.
5. Evidence over assertion.
6. Replaceable models, agents and harnesses.
7. Progressive disclosure.
8. Local-first by default.
9. Human authority at meaningful gates.
10. Observability is a feature.
