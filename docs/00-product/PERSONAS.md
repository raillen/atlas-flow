# Personas

## Solo Builder
Uses several AI models and wants one durable workflow. Values low setup, routing, cost visibility and recovery.

## Technical Founder
Starts from an idea and wants product/architecture documentation before execution. Values Discuss mode and clear Goals.

## AI-heavy Engineering Team
Uses multiple coding agents/providers. Values shared policy, cross-provider review and auditability.

## Framework Maintainer
Maintains Project Atlas/agent practices. Values reusable Skills/Agents/Recipes and compatibility.
