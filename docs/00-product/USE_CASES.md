# Primary Use Cases

## Start from an idea
Discuss → Decisions/Open Questions → Project Draft → readiness → Finalize → Project Atlas docs/ADRs/profile/Goals.

## Execute a Goal
Locked Goal → context pack → task DAG → workforce → route → worktrees → implementation → verification → review → evidence → gate.

## Change architecture
Discuss proposal → impact analysis → explicit acceptance → ADR/amendment → docs/Goal impacts.

## Recover after interruption
Load operational state → validate Git truth → reconcile worktrees/sessions → resume only pending work.

## Swap coding harness
Replace runner implementation without changing Goal/Agent/Skill/Recipe semantics.
