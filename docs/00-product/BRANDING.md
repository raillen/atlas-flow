# Branding Direction

## Name
**Atlas Flow**

## Relationship
Project Atlas Framework = protocol/knowledge/policy. Atlas Flow = execution/orchestration.

## Personality
Calm, technical, approachable and precise. Avoid gamer/cyberpunk excess.

## Visual language
Graphite neutral surfaces, cyan-blue primary accent, restrained semantic green/amber/red, clear typography and generous spacing. Color is never the only state cue.

## Logo
Simple atlas/grid node crossed by a directional flow path; recognizable at app-icon size.
